BLEACH: 영해의 균열 · 기술 연출 0.8.0

여섯 인물의 기술 30개마다 독립적인 형태·움직임·입자 배치·효과음을 사용합니다.
루키아: 설백일섬의 두 냉기 궤적 / 빙결진 눈꽃 문양 / 서리걸음 얼음 길 / 백련빙주 세 결정 기둥 / 백하 빙관과 눈꽃 폭풍.
오리히메: 삼각 꽃 결계 / 한 쌍의 치유 꽃 / 관통 꽃잎 창 / 사각 반격 결계 / 육화 결계와 여섯 꽃.
요루이치: 이중 발차기 뇌광 / 지면 낙뢰 / 세 방향 순홍 궤적 / 흑묘 회피 잔상 / 뇌신 수직 낙뢰와 전격 연무.
소이폰: 일침과 나비 표식 / 날개 모양 순보 궤적 / 다섯 침의 수렴 / 이중 표식 폭발 / 조준 고리와 영자포.
란기쿠: 재 칼날 부채 / 떠도는 재안개 / 안쪽으로 수렴하는 칼날 / 세 갈래 분진 폭발 / 나선형 은회 회오리.
우노하나: 청록빛 치유 수면 / 진홍색 일섬 / 교차 반격 검격 / 치유·검귀 쌍색 자세 / 진홍 검격 영역과 회복 파동.

표현 방식
이미지 원본과 전투 수치는 바꾸지 않습니다. Unity uGUI 메시에 결정·꽃잎·번개·궤적·문양·칼날을 그리며 공유 가산광 셰이더를 사용합니다. 새로 생성하는 효과 오브젝트는 없고 6개 시전 풀과 실제 상태 표시용 4개 슬롯을 재사용합니다. 한 레이어의 정점 수는 12,000으로 제한합니다. 바닥 이펙트는 적 공격 예고보다 아래에 두고, 모든 효과의 레이캐스트를 끕니다.

실제 시전의 AttackSerial과 전투 시계로 시작·타격·소멸을 정합니다. 거절된 입력은 효과를 만들지 않습니다. 일시정지에서는 시계가 멈추며 귀환·새 전투에서는 남은 효과와 효과음 이벤트를 정리합니다. 보호막·반격·설치된 재구름·적별 표식은 실제 모델 상태를 따라갑니다. 효과 줄이기는 주요 문양을 남기면서 입자·원호 분할 수·빛의 강도를 줄입니다.

효과음
30개 기술에 서로 다른 파형을 합성했습니다. 냉기 유리음, 꽃 결계 종소리, 전기 파열음, 벌침의 높은 바람음, 재구름의 금속성 바람, 치유·진홍 검격의 저음을 구분합니다. 실제 시전과 명중 이벤트에 연결하며 효과음 끄기 설정을 적용합니다. 음성 연기와 상업용 녹음 에셋은 포함하지 않습니다.

검증
모델에서 실제 기술 ID·전용 모티프·서로 다른 30개 파형·음량·셰이더 오류를 확인합니다. Windows 두 화면 크기의 실제 Unity 렌더에서 30개 기술을 버튼으로 사용하고, 표시된 모티프·정점 수·입력 통과·풀 재사용·소멸·효과 줄이기·일시정지를 검사합니다. 여섯 각성기의 30Hz 고정 스텝 영상과 동일 효과음 발생 시점도 내보냅니다. 영상은 성능 측정이나 아이폰 실기기 녹화가 아닙니다.
