BLEACH: 영해의 균열 · iPhone 빌드 0.13.0

대상: iPhone 15 Pro, iOS 17 이상, 가로 양방향, Metal, ARM64.
화면: Screen.safeArea 적용, 이동 패드와 공격·기술의 독립 포인터 처리, 큰 조작 버튼·대화 글자·선명도·키 안내 설정, 60fps 목표.
원본 PNG는 유지하고 iOS 임포트에 ASTC 6x6을 사용합니다.

제작
1. Unity 6000.3.27f1과 iOS Build Support에서 Tools/export-ios.ps1 실행.
2. Tools/IOSBuild.py prepare로 Builds/iOS-Xcode를 봉인하고 모든 파일의 SHA-256 목록 생성.
3. 공개 저장소 yjmjeminq/bleach-spirit-tide-ios의 수동 macOS workflow에 입력 릴리스 태그와 SHA-256 전달.
4. Mac에서 입력 파일 검증 후 Xcode로 iOS 기기용 ARM64 앱을 컴파일. 서명 없이 Payload/*.app 구조의 IPA 작성.
5. 다운로드한 IPA의 SHA-256·ZIP CRC·Mach-O 기기 플랫폼·앱 ID·버전·게임 데이터 전체 목록·실행 권한을 검증.

빌드에서 Apple 계정·인증서·프로비저닝 프로필은 사용하지 않습니다. 배포 IPA는 unsigned이며 iLoader가 사용자의 설치 절차에서 서명합니다.
다른 게임의 저장소와 IPA는 수정하지 않습니다. 공개 대상에는 생성 빌드 캐시·개인 게임 저장·로컬 인증 설정을 포함하지 않습니다.

검증 범위
Windows의 2556x1179 가로 화면과 예시 안전 영역에서 실제 uGUI 렌더·이벤트 기반 터치 검사를 수행합니다. 서로 다른 포인터 ID로 패드 유지 중 공격과 공격 해제, 다른 손가락의 패드 탈취 방지, 일시정지와 재개 시 눌림 해제를 확인합니다. 이는 실제 아이폰 하드웨어의 멀티터치·회전·발열·지속 프레임·Metal 렌더 검증이 아닙니다.
Mac 컴파일 성공과 IPA 파일 검증도 실제 설치·게임 플레이 성공을 뜻하지 않습니다. 실기기 검증은 설치 후 별도로 확인해야 합니다.

설치 후 첫 확인
1. IPA를 iLoader에서 선택해 서명·설치.
2. 새 프로필은 이야기 시작에서 선두를 고르고 강변 첫 전투로 진입. 기존 프로필은 이어서 하기에서 현재 목표 확인.
3. 텟사이 수련장에서 왼손 이동을 유지하며 오른손 공격·기술·회피.
4. 양쪽 가로 방향에서 노치·홈 표시 영역과 버튼 간섭 확인.
5. 일시정지·앱 전환·복귀 후 조작이 눌린 상태로 남지 않는지 확인.
6. 첫 의뢰·첫 던전·귀환·앱 재실행 후 저장 이어하기 확인.
