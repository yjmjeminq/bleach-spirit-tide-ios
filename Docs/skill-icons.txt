BLEACH: 영해의 균열 · 기술 그림 아이콘 0.9.0

여섯 캐릭터의 기술 30개를 서로 다른 그림으로 표시합니다. 전투의 기술 버튼과 기술 도움말에 같은 그림을 사용합니다. 각성기는 금색 테두리로 구분합니다.

각 버튼은 큰 그림, 짧은 기술명, 영압·재사용 시간으로 구성합니다. 재사용 중에는 그림 위에 원형 진행 표시와 남은 시간 숫자를 겹칩니다. 영압이 부족하면 그림의 밝기를 낮추고 이유를 표시합니다. 기술 이름 전체와 효과 설명은 도움말에서 확인합니다.

제작
built-in image_gen으로 각 캐릭터의 아이콘 시트 6장을 생성했습니다. 루키아 시트를 화풍·배치 참고로 사용해 나머지 다섯 시트를 생성했습니다. 원본 PNG는 그대로 보관하며 Unity Sprite.Create와 Data/skill_icons.json의 영역 정보로 기술별 그림을 읽습니다. 픽셀을 편집하거나 캐릭터·기존 적·배경 그림을 바꾸지 않았습니다. 원본 경로·SHA-256·전체 프롬프트는 skill-icon-art-sources.json에 있습니다.

검증
실제 기술 ID·그림 영역·원본 크기와 인접 영역 분리를 확인합니다. Windows 실제 Unity 화면에서 여섯 캐릭터의 전투·도움말 버튼 30개와 누르기 영역, 짧은 기술명이 실제 글자로 렌더되는지, 실제 기술의 재사용 시간·영압 부족 표시·입력 차단을 검사합니다. 2556x1179의 예시 아이폰 안전 영역을 포함하며 실제 아이폰 설치·하드웨어 터치는 별도 확인이 필요합니다.
