실행 중 찾은 오류도 수정했다. 보고 후 마을 지도가 이전 액트에 머무르던 상태, 마지막 조사 기록에 중간 단서가 남던 상태, 이후 액트에 나타난 내부 ID, 설명과 실제 적이 달랐던 구역, 호위 대상이 없는 ‘호위’ 명칭을 정리했다. 캐릭터 시트는 NPOT 자동 변환을 꺼 비율을 유지하고 발 기준 피벗과 연결 성분 크롭 정보를 적용했다. 이웃 셀이 보이던 우노하나 회수 프레임은 사용하지 않는다. 새 연계 설명을 넣은 조작 안내의 높이 초과와 NPC 몸체 터치 검사 좌표도 실제 화면 기준으로 고쳤다. 보스 대화가 끝난 뒤 남던 ‘계속’ 안내는 이전 전투·결과 안내로 복구하며 모든 장면 종료에 대한 회귀 검사 82개를 추가했다.

완주 가능성과 조작 검증은 재미를 보장하지 않는다. 이번 전투 검토에서는 접근 → 기본 명중 → 기술 연계 → 띄우기 → 공중 공격 → 강공격·각성기 → 정령 안내 → 다음 방의 흐름이 실제 입력으로 이어지는지 확인했다. 기존 동일 전투 반복에 배치·증원·환경 해제 선택을 추가했고, 보스는 무작정 연타하는 대신 자세 붕괴와 확정 사선을 읽도록 했다. 효과 줄이기는 화면 흔들림을 줄이되 타격 정지와 전투 규칙을 유지한다.

현재 확인한 빌드 GUID는 `de46d381d8c2401bbc8870eb3c12fa7e`이다. 빌드 오류·경고는 0개, 모델 1,724개, Windows 1560×720 및 2556×1179 실행 검사는 각각 4,955개가 통과했다. 정상 체력·실제 보상·수동 출구 접근을 사용하는 6캐릭터 모델 캠페인 180던전·684방과, 각 해상도의 네이티브 전체 캠페인·재현을 확인했다. 완료·보고·장비·저장 복구의 이전 회귀 검사도 유지했다. 정확한 코드 해시와 검사명은 QA/verification.json 및 세 보고서에 있다.

전투 영상은 고정 1/30초 시뮬레이션 입력으로 360장을 렌더한 12초 자료이며 실제 프레임 성능 측정이 아니다. 소리는 같은 게임 효과음 클립을 이벤트 시간에 합성한 데이터다. 하드웨어 출력 녹음·아이폰 실행·Metal·실제 멀티터치·발열은 검증하지 않았다.

그림은 여전히 시제품이다. 동작 시트는 오리히메·우노하나 두 명의 선택 프레임을 사용하며 네 명은 원본 포즈와 코드 모션을 사용한다. 일부 동작 시트 및 우노하나 정리 생성이 이미지 도구의 안전 심사에서 거절되었다. 원본 PNG를 보존하고 사용 가능한 프레임과 엔진 측 메타데이터로 처리했다. 완성된 연속 애니메이션과 모든 적의 동작, 제작용 음향·효과는 남아 있다. 새 이미지 13장의 프롬프트·해시는 experience-art-sources.json에 기록했다.

다른 게임과 원작의 참고 자료는 0.3.0의 campaign-review.md 및 canon-sources.json에 남아 있다. 던전 → 보급·정비 → 다음 지역의 반복과 비용을 확인하는 장비 선택을 참고했고, 이번 구조 등불·환경 해제·자세 수치는 이 게임의 규칙으로 설계했다.
