0.10.0 RPG 비교 검토 · 2026-11-06
요청: 다른 RPG 게임들을 확인하면서 기능과 스토리 흐름을 보완하기.
기준: 실제 0.9.0 게임 소스와 QA/verification.json. 이미 있는 기능을 새 기능으로 세지 않는다.

확인한 공식 자료
1. Dungeon Fighter Online / Scenario Dungeon
https://www.dfoneople.com/news/updates/406/Dungeon-Update/Scenario-Dungeon
던전 슬롯의 해당 퀘스트 정보, 본편·보조 이야기의 표시, 정화 후 다음 던전으로 이어지는 동선을 확인했다. 이 게임에서는 다음 목적지 이름과 전투 결과의 단서를 함께 이어 주는 데 참고했다.
2. Dungeon Fighter Online / Additional Changes
https://www.dfoneople.com/news/updates/4057/Additional-Changes
전투 콘텐츠를 Training Room에 추가하는 구조를 확인했다. 이 게임의 보스 기록 연습은 실제로 만난 기록만 열고 보상·소모품·본편 기록을 유지하는 별도 설계다.
3. FINAL FANTASY XIV / Navigating the Game Screen
https://eu.finalfantasyxiv.com/game_manual/view/
Main Scenario Guide가 다음 본편 의뢰 위치를 안내하고, Duty List의 제목과 목표가 수첩·지도에 연결되는 방식을 확인했다. 이 게임에 이미 있던 목적지 추적에 재접속 시 사건의 이유와 확인한 증거를 더하는 방향으로 적용했다.
공식 자료의 기능이 이 프로젝트에 그대로 들어 있다는 뜻은 아니다. 아래 개선은 현재 게임의 문제를 보고 내린 설계 판단이다.

플레이 흐름 검토와 반영
- 시작·복귀: 빠른 메뉴와 정확한 목적지 추적은 기존에 있다. 하지만 긴 대화록을 뒤지지 않고 현재 사건의 이유·최근 단서·해야 할 일을 읽는 화면이 없었다. 지난 이야기는 현재 액트와 실제 정화·보고 상태로 구성한다. 미래 액트, 미확인 결말은 표시하지 않는다.
- 정비·성장: 장비 비교·필터·확정 강화·보급은 기존에 있다. 출정 준비에 보유 회복 영자와 실제 착용 수치, 더 나은 보유 전리품의 유무를 연결한다. 장비는 직접 고르며 화면을 읽는 것만으로 착용·강화·구매하지 않는다.
- 전투 학습: 자유 수련은 기존에 있지만 보스 재현 API를 고르는 화면이 없었다. 본편에서 만난 보스 10명의 기록을 열고 실제 패턴을 연습한다. 기존 설계 데이터의 '4초 그로기' 등은 현재 전투 코드의 쉬는 시간과 달라 안내에 사용하지 않는다. 실제 TideSession.Enemies.cs에 맞춰 사선·점프·두 원·환영·미래 확정을 설명한다.
- 실패·재도전: 기존에는 재도전·마을 버튼만 있었다. 실제 마지막 피격의 적과 공격 예고를 보존해 알려 주고, 패배 화면에서 준비 확인 후 돌아와도 전투 시계와 체크포인트를 유지한다. 연습 중 회복은 본편 소모품을 차감하지 않는다.
- 이야기 호흡: 중간보스 결과에서 바로 다음 전투로 가는 선택만 두드러졌다. 다섯 액트에 선택적인 '동료와 잠시 정비'를 연결한다. 현재 선두의 기존 동료 장면을 실제로 읽고 빠른 메뉴로 돌아와 정비·이어서 출정을 선택한다. 본편 진행이나 보상을 중복하지 않는다.
- 인과관계·인물: 중간보스 정화 5장면과 액트 보고 4장면에 13문장을 보강했다. 얻은 증거와 다음 현장 조사를 연결하고 오리히메의 선택, 소이폰의 합류, 란기쿠의 멈춰 있을 시간을 지킨다. 5액트·30던전·184장면과 선택 의뢰 15개의 구조를 유지한다.
- 기존 기능 보존: 캐릭터 6명·그림 기술 아이콘 30개·전용 효과·자동 저장·선택 의뢰·지도 복귀·대화록·터치 동시 입력은 전체 회귀 검사의 대상이다.

완료를 증명할 기준
A. 공식 RPG 자료를 읽고 현재 코드의 부족한 부분과 적용 판단을 이 문서에 연결한다.
B. 5액트 30구역과 수락 전·보고 전·완료 상태의 지난 이야기가 현재 진행에 맞고, 열람만으로 저장 데이터가 변하지 않는다.
C. 출정 준비에서 실제 보유·착용 수치를 보며 직접 장비 화면으로 이동한다. 이전 메뉴로 정확히 돌아간다.
D. 미확인 보스는 UI와 세션 API 양쪽에서 막는다. 만난 보스 10명을 실제로 선택·전투·승리하며 보상과 소모품·진행이 유지된다.
E. 패배 원인을 실제 피격에서 얻는다. 준비 보기·뒤로가기로 패배 상태와 시계가 보존되고 재도전은 원래 체크포인트를 사용한다.
F. 5개 중간보스 뒤 선택적인 동료 장면을 실제로 읽고 정비 메뉴에 도착한다. 전리품·경험치·현재 다음 구역은 바뀌지 않는다.
G. 보강한 9개 장면의 대본·게임 JSON이 일치하며 모든 선두·최대 글자 크기에서 읽을 수 있다. 미래 이야기와 미선택 결말은 계속 잠긴다.
H. 새 Unity 빌드로 모델 검사와 PC·iPhone 15 Pro 비율의 전체 캠페인·UI 검사를 통과한다. 기존 이미지 원본은 해시로 유지한다.
I. 새 iOS ARM64 IPA를 만들고 내려받은 버전·해시·기기 플랫폼·게임 데이터를 검증한다. 실제 아이폰 실행은 별도 사실로 표시한다.

검사 상태와 실제 증거
현재 결과는 QA/rpg-flow-verification.json과 QA/verification.json에 묶는다. 빌드 GUID·코드 해시·각 해상도의 원본 보고서·실제 화면을 확인한다. 이전 0.9.0 결과를 새 기능의 통과 근거로 사용하지 않는다.
