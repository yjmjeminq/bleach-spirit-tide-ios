2026-11-05 스토리·조작·진행 검토

이번 검토는 ‘왜 다음 장소로 가는가’, ‘돌아왔을 때 마을이 어디까지 기억하는가’, ‘재도전이 이야기를 되돌리는가’를 기준으로 진행했습니다. 5개 액트의 서사 연결을 읽고 고쳤으며, Unity에서는 Act 1의 두 보스를 실제 흐름으로 연결해 반복 검사했습니다.

슈리커를 제압하자마자 이유 없이 다음 보스 버튼을 누르던 흐름에 ‘사역체의 신호가 등대로 수렴한다’는 원인을 넣었습니다. 등대 진입 전에는 소리를 흩뜨린 함정과 사람을 유인한 미끼의 역할을 구분합니다. 최종 승리 뒤에는 아직 분석 전인 흔적을 마을로 가져오고, 보고가 끝나야 가르간타라는 이름을 확정합니다.

‘미끼를 구분하라’는 대사에 대응하는 실제 전투 신호도 넣었습니다. 그랜드 피셔는 당시 플레이어 위치에 주황색 미끼와 원형 범위를 고정하며, 회수 뒤 1.3초 동안 본체 타격 피해가 25% 증가합니다. 슈리커와 공격 순서도 다릅니다. 안전한 귀환 등불과 미끼의 표시를 구분하고, 효과 줄이기 설정에서도 위치와 공격 판정은 동일하게 유지합니다.

NPC는 의뢰 전 / 슈리커 조사 중 / 그랜드 피셔 추적 중 / 보고 대기 / 보고 완료의 다섯 단계에 맞춰 반응합니다. 중간 귀환 때 완료한 함정을 다시 조사하라고 하지 않고, 최종 귀환 때 쿠카쿠가 우라하라에게 직접 안내합니다. 수련·장비·보급은 본편 목표를 덮어쓰지 않습니다. 여섯 인물 모두 자신의 말투와 역할에 맞는 출정·추적·귀환 응답을 갖습니다.

콘이 동료의 말을 전하는 대사에는 말한 인물을 명시했습니다. 보고 후에는 과거의 말을 회상하는 문장으로 처리합니다. 여섯 동료의 응답은 큰 글자 설정에서도 실제 대화 카드 안에 들어가는지 확인합니다.

Act 1의 사건 설명과 던전 순서가 어긋나던 애시드와이어 장면을 슈리커보다 앞에 놓았습니다. 이미 사용할 수 있던 각성기를 Act 3에서 다시 ‘첫 해금’하던 모순은 ‘각성기 강화’로 바꿨습니다. 긴과 란기쿠의 대사는 중간보스 직후 장면으로 옮기고, Act 4의 종료 대사는 환영이 걷힌 뒤 퀸시 통로를 확인하는 내용으로 바꿨습니다.

과거에 죽었거나 다른 시대에 있던 적들이 같은 군대로 합류하는 설명을 쓰지 않습니다. 현장의 적은 영해가 재현한 위협입니다. 원작 권능을 영구히 무효화하는 만능 장치를 얻는 대신, 이 전장과 균열의 연결만 봉인합니다. 구조한 이름을 강화 재료로 소비하거나 수집 누락 때문에 본편 결말이 잠기는 조건도 두지 않습니다.

진행 검사는 장면 도중 마을로 복귀, 같은 대화 버튼 두 번 입력, 중간보스 뒤 귀환·재출정, 최종 보스에게 패배·즉시 재도전, 보고 전 재출정 차단, 보고 보상 중복 요청, 완료 후 재현 전투를 포함합니다. 장면 중에는 전투 시계가 멈추며, 취소와 패배는 획득한 단서를 되돌리지 않습니다. 재현 전투는 보상·조사 상태를 바꾸지 않고 결과 문구도 이미 완료한 사건으로 표시합니다.

실행 화면에서 마을 버튼이 캐릭터를 가리던 배치, 한글 이름의 어색한 줄바꿈, 아래쪽 상태 문구 잘림을 수정했습니다. 아이폰 비율에서는 이동 패드와 NPC 버튼이 겹치고 보스 일부가 기술 버튼 뒤에 놓이는 현상도 찾아 버튼 간격과 카메라 기준점을 조정했습니다. 실제 렌더링 뒤 버튼끼리의 겹침, 이동 패드와 버튼의 겹침, 텍스트 높이를 검사합니다.

효과 줄이기 설정은 시각 효과만 바꿉니다. HTML 시안에서 이 설정이 공격 시간을 줄이던 버그를 제거했고 Unity 모델에서도 피해량과 전투 시간이 같음을 확인합니다. 회복 영자는 실제 터치 버튼과 V 키로 사용할 수 있습니다. 장비 화면에 표시하는 ‘타격 피해 +2’는 실제 판정과 일치합니다. 장비 즐겨찾기는 유지 상태를 표시하며 아직 없는 분해·판매 기능을 안내하지 않습니다.

저장 복구 검사는 정상 저장, 이전 저장 복구, 주 파일 누락, 두 파일 손상, 복구 직후 재저장까지 연속 실행합니다. 손상 주 파일의 교체에서 Windows 파일 제거 오류가 발생하는 조건을 확인해, 손상 파일을 별도 보존 경로로 보내면서 정상 복구본을 유지하도록 수정했습니다. 정상 파일을 손상본으로 덮어쓰는 회귀도 함께 검사합니다.
