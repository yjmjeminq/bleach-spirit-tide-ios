BLEACH: 영해의 균열 · UI 편의성 검토 0.7.0

마을의 메뉴에서 설정을 먼저 찾던 흐름을 빠른 메뉴로 바꾸었습니다. 다음 의뢰·보고·조사를 큰 주 행동으로 표시하고 여섯 서비스와 도움말에 직접 접근합니다. 전투 메뉴는 일시정지와 계속·귀환 동작을 유지합니다.

부탁의 목적지를 액트만 안내하던 동작을 던전·방까지 지정하도록 고쳤습니다. 목적지 카드와 출정 버튼을 연결하며, 다른 액트를 보다가도 목적지 액트로 되돌릴 수 있습니다. 장치 요청은 저장 방 이후의 현재 던전을 우선합니다. 목표 방을 이미 지나쳤다면 정화 후 재현이라는 제한을 표시합니다. 잠긴 구역에 들어가거나 방 체크포인트를 지우지 않습니다.

이전 메뉴의 모드뿐 아니라 의뢰 상세·필터·선택, 장비 정렬·쪽·선택, 기록 액트·장면·문장·목록, 지도 목적지와 버튼 선택을 스택에 저장합니다. 돌아오기가 보상·전투 시간을 변경하지 않게 합니다.

장비는 전체·공격·수호로 좁히고 최근 획득·성능순으로 봅니다. 착용 중인 같은 슬롯과 실제 공격력·체력의 차이를 보여줍니다. 착용 중인 항목은 재착용을 막고 강화 재료가 부족하면 비용과 원인을 보여줍니다. 새 전리품의 상세와 보이는 목록이 일치하도록 해당 쪽을 엽니다. 원본 보유 배열의 순서는 변경하지 않습니다.

진행 대화에 이전 문장을 추가했습니다. 뒤로 읽는 동안 완료 콜백과 보상은 실행하지 않으며 최초 문장에서는 버튼을 비활성화합니다. 대화록에는 이미 열린 장면만 액트·본편·동료·부탁별 여섯 개씩 찾아보는 목록을 넣었습니다. 새 장면을 열거나 선택하지 않은 결말을 드러내지 않습니다.

휴대기기와 아이폰 비율 검사에서는 A/S/D/F/R·Q·V·E 키 안내를 자동으로 줄입니다. 설정의 키 안내는 자동·표시·숨김으로 저장하며 이전 저장은 자동을 기본값으로 받습니다. 도움말에도 터치 입력에 맞는 기술 번호를 표시합니다. 저장 완료 표시는 실제 저장 성공 뒤에 갱신하고, 실패하면 확인 필요 상태를 표시합니다.

검증 방식
같은 빌드 GUID의 모델 검사와 Windows 1560x720·2556x1179 실제 uGUI 렌더·포인터 이벤트 검사를 사용합니다. 48개 장비와 최대 대화 글자 조건에서 배치·터치 영역·필터와 정렬·강화 왕복·장면 바로가기·목록의 쪽 복원·지나온 던전 목적지 직접 출정·현재 장치 경로·체크포인트 제한·이전 문장과 진행 불변·키 안내를 확인합니다. 전체 5액트 캠페인과 기존 의뢰·대화 검사도 같은 실행본에서 수행합니다.

원본 PNG와 보상·전투·해금 규칙을 수정하지 않습니다. iPhone 실기기 멀티터치·Metal·발열·성능과 IPA 작업은 범위 밖입니다. 실제 기기 검증 완료로 표기하지 않습니다.
