0.6.0 · 메인·서브 퀘스트와 몰입 흐름 검토

요청: 자연스러운 메인 퀘스트와 서브퀘스트를 추가해 게임에 몰입할 수 있게 만들기.

주요 의뢰
5개 챕터를 이름과 인물의 부탁으로 연결하고, 기존 던전 단계 30개에 필수 현장 조사 5개를 더했다.
액트마다 4구역 첫 통로의 전투 후 주요 표지를 직접 살피면 동료가 단서의 의미를 말한다.
아직 살피지 않은 표지는 출구와 체크포인트로 건너뛰지 못한다. 조사 전 귀환은 해당 방, 조사 후 귀환은 다음 방부터 재개한다.
이전 저장은 이미 지나온 방과 보고에서 조사 완료를 복원하며, 새 서브퀘스트의 완료나 보상을 만들어 내지 않는다.

선택 의뢰
각 액트 3개, 총 15개이며 모두 두 단계의 실제 목표와 소식 전달을 가진다.
현장 메모·이름표·지도·귀환 표지 확인, 해당 액트의 실제 장치 해제, 다른 인물과 이야기, 실제 기술 연계·정밀 회피 수련을 사용한다.
수락 전에 했던 행동이나 단순히 대화록을 읽은 것은 목표로 치지 않는다. 목표와 다른 인물·액트·방을 조사해도 진행하지 않는다.
메인 엔딩은 선택 의뢰 완료를 요구하지 않는다. 뒤늦게 발견한 부탁은 정화한 던전의 재현으로 수행할 수 있다.
지나온 의뢰의 대사는 ‘지난 부탁’으로 표시해 당시의 일과 현재 상황을 구분한다.

인물과 대화
콘은 돌아오는 불빛과 기다리는 사람을 챙긴다. 텟사이는 손에 맞는 매듭과 쉼터를 준비한다.
뱌쿠야는 짐작으로 이름을 채우지 않고, 우라하라는 서로 다르게 본 것을 나란히 남길 방법을 제안한다.
쿠카쿠는 앞서 가는 사람뿐 아니라 돌아오는 쪽의 길도 남긴다.
오리히메는 읽고 전할 방법을 스스로 고르며, 소이폰은 요루이치에게 혼자 기다리지 않아도 되는 신호를 배운다.
란기쿠의 편지 의뢰는 말하지 않아도 되는 자리와 말할 수 있는 자리를 함께 남긴다. 긴이 실제로 돌아왔다는 해석을 만들지 않는다.
마지막 찻잔 의뢰는 앞선 동료 대화와 메인 후일담의 약속을 준비하는 작은 일로 이어진다.

선택의 결과
이름을 직접 전하기/등불에 답장 걸기, 오리히메가 읽기/우노하나와 함께 읽기, 편지 접어 두기/동료 앞에서 읽기의 세 갈래 의뢰에 각각 두 결말이 있다.
다른 12개 의뢰와 합쳐 보고 결과는 18개다. 각 선택의 보상량은 같으며 이후 대화와 이야기 기록이 바뀐다.
보고 대화를 마친 뒤에만 보상을 한 번 지급한다. 선택하지 않은 결말은 대화록에서 숨긴다.
의뢰자에게 다시 이야기하면 전한 소식에 맞는 말을 듣고, 상점 게시판에도 가장 최근의 이야기가 남는다.

실제 조작 연결
마을의 의뢰 수첩(Q), NPC 대화창의 부탁 버튼, 액트별 주요/마을의 부탁 탭, 수락 대화, 목표 추적, 목적지 지도·수련장·대화 연결을 제공한다.
주요 단서와 선택 단서는 다른 색으로 표시하고, 가까운 대상에 맞춰 현장 E 버튼이 바뀐다.
같은 방에 두 단서가 있을 때 선택 목표만 수행해서 주요 증거가 생기지 않으며, 주요 증거를 찾아도 선택 보상이 자동으로 지급되지 않는다.
기존 수련 적은 공격하지 않아 회피 의뢰를 할 수 없었다. 실제 예고 공격을 켜는 수련 방식을 더했고, 수련 중 체력은 1 아래로 내려가지 않는다. 재화와 메인 진행에는 영향을 주지 않는다.
타격이 연결되지 않거나 사용할 수 없는 기술 요청을 실제 연계 성공으로 세지 않도록, 성공한 동작에만 수련 목표를 연결했다.
NPC 부탁 버튼이 대화창 갱신 후 사라지는 문제는 새 버튼을 생성한 대화 카드에 직접 붙여 해결했다.

대본과 저장의 기준
Tools/prepare_quests.py: 메인 5개·선택 의뢰 15개의 목표·인물 대사·선택 결과 작성 원본.
Tools/prepare_dialogue.py: 기존 대사와 새 의뢰 대사 73장면을 합쳐 내보내는 작성기.
Assets/SpiritTide/Resources/SpiritTide/Data/quests.json: 실제 목표와 보상, 발생 조건, 선택 결과.
Assets/SpiritTide/Resources/SpiritTide/Data/dialogue.json: 총 184장면, 공통 대사 513개와 선두 응답 150개.
Docs/quest-script.txt: 메인·서브 의뢰 조건과 전체 대사·각 선택 결과·후속 반응.
Docs/character-dialogue-script.txt: 전체 사건 순서와 캐릭터별 대화록.
저장에는 수락한 의뢰·현재 단계·선택·보고 완료·주요 조사·추적 상태가 남는다. 이야기 기록은 장비 칸을 쓰지 않는다.

검증 범위
QA/quest-verification.json과 QA/dialogue-verification.json에 현재 빌드 GUID, 데이터·대본 해시와 검증 항목을 묶는다.
모델에서 여섯 캐릭터의 정상 체력 전체 캠페인 180던전·684방, 주요 현장 조사 5개와 조사 전후 귀환, 선택 의뢰 18개 결과의 실제 목표·보상 1회·저장 재시작을 확인한다.
Windows 실제 실행에서는 정상 캠페인과 엔딩 뒤 선택 의뢰 15개를 전부 수락→수행→보고하고, 이후 NPC 말과 대화록에 결과가 남는지 확인한다.
진행 중인 Act 2의 프로필을 사용하는 추가 검사에서는 첫 번째 귀환 매듭부터 실제로 남긴 뒤 4구역으로 가서 메인·서브 단서의 공존과 개별 판정을 확인한다.
모든 대사 184장면×6선두의 본문 높이와 의뢰 카드·현장·수련·보고 화면을 두 해상도에서 확인한다.
아이폰 실기기·iOS·Metal·멀티터치·음성 연기를 검증한 결과는 아니다. IPA 제작은 보류 상태다.
