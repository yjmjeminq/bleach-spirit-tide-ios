0.11.0 움직임 개선 · 목표와 검증 기준
요청: 캐릭터들의 움직임을 아주 자연스럽게 만들기.
기준 버전: 0.10.0 빌드 6. 기존 원본 이미지·아이콘·세계관·게임 진행은 보존한다.

확인한 원인
- 루키아·요루이치·소이폰·란기쿠는 한 장의 그림 전체를 기울이고 늘리는 표현이다.
- 오리히메·우노하나는 적은 수의 서로 다른 포즈를 시간 구간별로 바꾼다. 실루엣·발 기준·크기가 함께 변한다.
- 걷기는 실제 이동량이 아니라 입력과 시간만으로 두 포즈를 고른다. 발 디딤·무릎·골반 움직임이 없다.
- 화면이 플레이어를 즉시 따라가고 배경은 다른 비율로 이동하여 미끄러지는 느낌을 키운다.
- 공격 예비 동작·타격·회수·점프·착지·회피·피격 사이의 자세 연결이 없다.

개선과 완료 기준
A. 여섯 인물 모두 새로운 기본 자세와 실제 팔·다리·손·발·척추 관절로 연속 동작을 그린다. 정지 그림의 회전이나 두 프레임 교체만으로 끝내지 않는다.
B. 실제 이동량에 맞는 걷기·달리기와 좌우·앞뒤·깊이 이동을 표현한다. 디딘 발은 지면에 머물고, 발을 들어 옮길 때 무릎이 굽는다. 벽에 막히거나 멈추면 달리기가 계속되지 않는다.
C. 여섯 인물의 대기·이동·3단 기본 연계·강공격·띄우기·공중 공격·반격·30개 기술·점프와 착지·회피·피격이 부드럽게 이어진다. 타격 시점은 실제 전투의 판정 시점과 맞춘다.
D. 얼굴과 체형의 크기, 팔다리 길이, 발 기준이 안정적이다. 무기는 손을 따라가며 몸에 그려진 칼이 다리와 함께 움직이지 않는다. 머리카락 등 후속 움직임은 인물의 디자인을 해치지 않는다.
E. 카메라 추적과 지면 이동을 맞추고 급격한 위치 변화를 완화한다. 적도 실제 이동·공격·피격에 반응하게 하며 이미지를 통째로 늘리는 표현을 줄인다.
F. 일시정지·타격 정지에서는 동작 시계를 멈춘다. 캐릭터 교체·귀환·새 방·재도전에서는 이전 발 고정과 자세를 안전하게 정리한다.
G. 모델과 실제 Unity 렌더로 여섯 인물 및 각 행동을 검사한다. 발 고정·관절 길이·상태 전환과 영상의 실루엣·연속성을 함께 확인한다. 좁은 자동 검사만으로 자연스러움을 단정하지 않는다.
H. 기존 5액트·30던전·114방·70적·대화·퀘스트·아이콘·효과·저장·터치 UI를 전체 검사한다. 새 IPA를 만들고 버전·기기 형식·게임 데이터·무결성을 검증한다. 실제 아이폰 실행 여부는 구분한다.

그림 제작
기존 비키니 디자인과 성인 인물의 얼굴을 참고해 built-in image_gen으로 여섯 장의 기본 자세 그림을 생성했다. 원본은 수정하지 않는다. 무기와 몸이 겹치지 않게 하고 관절에 연결할 수 있는 자세를 사용한다. 파일·전체 프롬프트·해시는 rig-art-sources.json에 기록한다. 정점·관절·UV 데이터는 코드로 작성하며 PNG 픽셀은 편집하지 않는다.

구현 기록
- 기존 46개 그림과 새 기본 자세 6개의 원본은 보존했다. 긴 뒷머리가 팔에 겹친 네 인물은 몸과 뒷머리를 별도로 편집한 8개 PNG를 추가했다. 원본 픽셀은 추가 편집하지 않으며 UV·관절 데이터로 연결한다. 추가 그림·전체 프롬프트·해시는 rig-layer-art-sources.json에 기록한다.
- 18개 관절의 두 링크 IK, 실제 지면 좌표의 발 고정, 거리 기반 보행 주기, 골반 지지 높이, 무기와 머리카락의 독립 움직임을 적용했다. 점프·착지·회피와 공격 취소 시 손목 및 무기 회전도 앞 자세에서 이어진다.
- 카메라는 이동 여유와 완만한 추적을 사용한다. 배경은 방 중앙을 기준으로 같은 거리를 이동해 좌우 끝에서도 화면을 채운다. 동일 깊이에서는 플레이어가 큰 적에게 가려지지 않게 표시한다.
- 적 70개 원본 그림은 체형 7종의 연속 표면으로 움직인다. 이동량에 맞춘 지지·복귀 보행, 날개·꼬리·촉수, 실제 예고·공격·경직 이벤트를 사용한다. 여섯 플레이어의 18관절 리그와는 구조가 다르다.
- 원본 일러스트의 얇은 선이 축소 시 깜빡이지 않게 동작 그림에 밉맵과 삼선형 필터를 적용했다. 화면의 UI 및 텍스트 크기는 유지했다.

검증 계획과 범위
- 모델: 여섯 인물 각각 720프레임 이동·정지·역방향·깊이 이동, 30/60/120Hz 비교, 12종 행동 변형, 관절 길이·발 고정, 일시정지·타격 정지·귀환, 달리기 중 공중 회피와 착지, 타격 뒤 회피 취소를 측정한다.
- 실제 Unity: 여섯 인물의 대기·이동·3연계·모으기·강공격·띄우기·공중 공격·회피·반격·기술 30개·실제 피격·벽에 막힘·귀환을 그린다. 적 70종을 확인하고 체형 7종의 실제 AI 공격과 정지를 확인한다. 양쪽 맵 끝의 배경 범위와 카메라 정지도 검사한다.
- 30fps, 1350프레임의 여섯 인물 동작 시퀀스에 실제 액션 종류·연계 단계·타격 이벤트와 18관절의 프레임별 기록을 남긴다. 이는 입력 재현 영상이며 기기 FPS 측정이 아니다.
- 최종 Windows 빌드와 같은 GUID의 전체 데스크톱·아이폰 비율 검사, iOS 내보내기와 Mac ARM64 빌드, IPA 데이터·버전·무결성 검증 후 배포한다. 실제 아이폰 설치·터치·Metal 성능 검사는 별도이다.
