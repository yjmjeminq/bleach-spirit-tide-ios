0.5.0 · 이야기 순서와 캐릭터 대화 검토

요청: 스토리에 따라 캐릭터 대화록을 정리하고 대화를 자연스럽게 만들기.

작성 범위
본편 75장면 = 30개 출정 + 10개 보스 대치 + 30개 정화 후 + 5개 귀환 보고.
동료 대화 30장면 = 여섯 인물 × 다섯 액트.
정령 구조 보고 5장면과 귀환 후일담 1장면을 더해 총 111장면.
공통 대사 324개, 선두별 응답 150개, 마을 NPC 진행 상태별 응답 105개.
원작 대사를 인용하지 않은 이 게임의 창작 대화이며 음성 연기는 포함하지 않는다.

편집 판단
1. 같은 귀환 문장을 다섯 액트에서 반복하던 구성과 보스별 공통 응답을 바꿨다.
2. 사건의 발견 → 동료의 질문·관찰 → 다음 행동이 이어지도록 발화를 나눴다.
3. 루키아의 담백한 말, 오리히메의 관찰과 의지, 요루이치의 여유, 소이폰의 공적 존대와 긴장, 란기쿠의 배려와 짧은 감정, 우노하나의 기다림과 단호함을 구분했다.
4. 오리히메가 길과 표지를 직접 찾고 의견을 말하게 했다. 요루이치와 소이폰의 대화에는 호칭과 서로의 걱정이 드러나게 했다.
5. 긴의 재현은 살아 돌아온 본인으로 다루지 않는다. 란기쿠의 출정·대치·정화 후 감정을 서로 다르게 쓰고, 동료가 기다리도록 했다. 우노하나에게 답할 때 존대를 맞췄다.
6. Act 3에서 원본을 회수한 뒤 귀환 보고에서 영압을 맞추고 각성기를 강화한다. 아직 만들지 않은 사본과 원본을 맞췄다고 말하던 문장을 없앴다.
7. 마지막 보고에는 여섯 인물이 모두 말한다. 다음 의뢰를 예고하는 문장 대신 휴식과 약속한 차로 사건을 마무리한다.
8. 조사 기록과 전투 결과는 사실 요약을 보여 준다. 같은 캐릭터의 감상 대사를 결과 화면에 다시 붙이지 않는다.

게임과 대화록
뱌쿠야 → 조사 기록 확인 → 대화록. 액트별 본편 순서 뒤에 동료 대화와 구조 보고를 모았다.
장면 이동과 대사 페이지 이동은 따로 제공한다. 미래의 장면 제목·대사는 진행 전 숨긴다.
처음 장면을 마쳤을 때의 선두를 저장하므로 캐릭터를 바꿔도 당시 응답이 남는다.
대화 이력이 없던 이전 저장은 완료한 구역과 보고로 장면을 복원한다. 복원한 장면은 현재 선두의 응답임을 표시한다.
대화록 읽기는 보상·조사 진행·대화 이력을 바꾸지 않는다. 의뢰 전 동료 대화, 장면 취소와 건너뛰기도 조건을 맞췄다.

권위 있는 데이터와 재생성
Tools/prepare_dialogue.py: 사람이 읽을 수 있는 작성 원본, 말투 지침과 단계별 대사.
Assets/SpiritTide/Resources/SpiritTide/Data/dialogue.json: 게임이 읽는 장면·선두 응답·NPC 반응.
Docs/character-dialogue-script.txt: 같은 데이터에서 내보낸 전체 대본. 결말 포함.
Docs/dialogue-index.json: 장면별 ID와 액트 목록, 개수, 작성 원본 위치.
작성기를 반복 실행해도 내용은 동일하며 기존 경험·스토리 데이터와도 함께 맞춘다.

검증 근거
QA/dialogue-verification.json: 현재 빌드 GUID, 게임 데이터와 대본 SHA-256, 검사 범위.
QA/model.json: 모든 장면의 6개 선두 응답 해석, 화자·조건·잠금, 기존 저장 복원, 실제 저장 재시작과 당시 선두 유지.
QA/player-desktop.json, QA/player-phone-layout.json: 최대 글자 크기에서 666개 장면 변형의 모든 페이지 높이, 실제 본편 75장면 기록, 동료 대화 30개와 전체 대화록 페이지 이동.
QA/60-rangiku-before-gin.png: 실제 동료 대화 카드.
QA/61-archive-a4_d3_clear.png: 이야기 순서와 당시 선두가 표시되는 대화록.
QA/62-archive-locked.png: 미진행 액트의 대화와 이름을 숨기는 화면.

자연스러움은 검사 개수만으로 판정하지 않았다. 인접한 발화와 앞뒤 장면을 읽으며 자기 말에 대답하는 표현, 같은 이별의 반복, 존대와 반말의 불일치, 아직 얻지 않은 정보의 단정을 수정했다.
현재 실행 확인은 Windows 렌더와 포인터 이벤트이며 아이폰 실기기·음성 연기 확인이 아니다. IPA 작업은 보류 상태다.
