BLEACH: 영해의 균열 · Unity 캠페인 검증본 0.9.0

Unity **6000.3.27f1** 프로젝트입니다. 루키아·오리히메·요루이치·소이폰·란기쿠·우노하나 여섯 인물로 5개 액트, 30개 던전, 114개 전투방을 진행합니다. Windows 실행본과 iPhone 15 Pro용 iOS 17 이상 가로 화면 빌드를 제공합니다. iPhone 빌드는 Unity IL2CPP → Xcode ARM64 → unsigned IPA 순서로 제작하며 iLoader에서 서명·설치합니다. 실제 아이폰 설치·플레이 검증과 파일·화면 검증은 구분합니다.

0.9.0에서는 기술 30개에 전용 그림 아이콘을 연결했습니다. 여섯 캐릭터의 아이콘 시트 6장을 built-in image_gen으로 생성했고, 원본 PNG를 유지한 채 Unity에서 각 기술의 영역을 읽습니다. 전투 버튼과 기술 도움말에 같은 그림을 표시합니다. 짧은 기술명, 원형 재사용 진행 표시, 남은 시간 숫자, 영압 부족 시 그림의 밝기와 설명을 함께 표시합니다. 원본과 프롬프트·해시는 `Docs/skill-icon-art-sources.json`에 있습니다.

0.8.0에서는 여섯 캐릭터의 기술 30개에 전용 이펙트와 효과음을 추가했습니다. 루키아의 눈꽃·얼음 기둥, 오리히메의 꽃잎 결계, 요루이치의 번개·질주, 소이폰의 침·나비 표식·영자포, 란기쿠의 재 칼날·소용돌이, 우노하나의 치유 문양·진홍색 검격으로 구분합니다. 각성기는 여섯 종류의 마무리 연출을 사용합니다. GPU에 그리는 코드 기반 효과이며 원본 PNG는 수정하지 않습니다. 실제 보호막·재구름·표식·반격 태세와 연동하며 효과 줄이기, 일시정지·귀환·캐릭터 교체를 처리합니다. 자세한 목록과 렌더 검증 범위는 `Docs/skill-effects.txt`에 있습니다.

0.7.1에서는 아이폰용 Xcode 내보내기, ARM64 Mac 빌드와 IPA 파일 검증을 추가했습니다. 원본 PNG를 바꾸지 않고 iOS 전용 ASTC 압축을 적용하며, 서로 다른 포인터 ID로 이동과 공격의 동시 입력·손가락별 해제·메뉴 진입 시 입력 초기화를 검사합니다. 아이폰 15 Pro의 3배 화면에서 44포인트 이상의 조작 버튼인지도 확인합니다. 제작 방법과 검증 한계는 `Docs/ios-build.txt`에 있습니다.

0.7.0에서는 마을의 ‘메뉴’를 자주 쓰는 기능의 빠른 메뉴로 바꿨습니다. 현재 의뢰 듣기·귀환 보고·조사 계속을 맨 위에서 선택하고, 의뢰 수첩·장비·지도·기록·보급·설정을 바로 엽니다. 뒤로 돌아오면 의뢰 상세, 장비의 슬롯 필터·정렬·쪽·선택, 지도, 대화의 문장과 목록 위치 및 키보드 선택을 복원합니다.

의뢰의 ‘목적지 보기’는 정확한 던전과 방을 표시합니다. ‘표시한 목적지로 출정’으로 해당 구역에 진입하며, 장치 해제는 현재 진행 가능한 장치부터 안내합니다. 목표가 저장된 방 뒤에 있으면 던전 정화 뒤 재현으로 방문하라는 이유를 표시합니다. 미해금 지역의 잠금과 주요 조사 조건은 그대로 적용합니다.

장비에는 전체·공격·수호 필터와 최근 획득·성능 정렬, 착용 장비와의 수치 차이, 강화 비용과 재료 부족 안내가 있습니다. 전투 결과의 ‘전리품 확인’은 새 장비가 보이는 쪽을 열어 선택합니다. 비교와 정렬만으로 장비를 자동 착용하거나 재화를 쓰지 않습니다. 대화 중 ‘이전 문장’을 누를 수 있고, 대화록의 ‘장면 목록’에서는 액트와 본편·동료·부탁별로 이미 열린 장면에 바로 이동합니다. 키 안내는 휴대기기에서 자동으로 숨기고 설정에서 자동·표시·숨김을 선택합니다. 저장 성공·실패는 우측 상단에 표시합니다.

UI 변경 검토는 `Docs/ui-review.txt`, 현재 빌드의 검사 근거는 `QA/ui-verification.json`에 있습니다. 데스크톱과 아이폰 비율의 Windows 실행본에서 터치 영역, 큰 글자, 메뉴 복귀, 목표 출정, 읽기 전용 동작을 검사합니다. iPhone OS에서 실행한 결과는 아닙니다.

0.6.0에서는 주요 의뢰 5개 챕터와 실제 목표를 가진 선택 의뢰 15개를 연결했습니다. 마을의 ‘의뢰 수첩 · Q’ 또는 NPC 대화창 오른쪽 위 ‘부탁’에서 확인합니다. 수락 대화의 마지막 선택으로 맡고, 현장·수련장·마을에서 두 단계의 목표를 수행한 뒤 소식을 전하면 보상을 받습니다. 각 의뢰의 선택과 진행은 자동 저장합니다.

주요 의뢰는 기존 30개 던전의 단서에 더해 액트마다 네 번째 던전 첫 통로에서 직접 살펴볼 단서를 가집니다. 전투 뒤 주요 표지를 가까이서 E 또는 버튼으로 살피면 대화가 이어지고 다음 통로와 체크포인트가 열립니다. 조사 전 귀환하면 해당 통로부터 다시 살피며, 조사 뒤에는 다음 방부터 이어집니다.

선택 의뢰에는 이름표·답장 찾기, 귀환 매듭 남기기, 다른 인물에게 소식 묻기, 실제 장치 해제, 수련장에서 기본 타격 후 기술 연계와 정밀 회피가 있습니다. 선택 의뢰는 메인 엔딩의 필수 조건이 아닙니다. 지나온 지역에서도 수락해 정화한 던전을 재현하며 수행할 수 있고, 당시 대사는 ‘지난 부탁’으로 구분합니다. 이름을 전하는 방식·읽어 줄 동료·편지를 두는 방식에 따라 3개 의뢰의 후속 대화와 이야기 기록이 달라집니다. 보상량은 같습니다.

보상은 의뢰당 경험치 40~80, 골드 90~170, 영자 결정 1~2와 이야기 기록입니다. 보고 대화를 마친 뒤 한 번 지급합니다. 장비 칸을 소모하지 않으며, 상점 게시판과 의뢰자의 말에 전한 소식이 남습니다. 수첩에서 추적할 의뢰와 목적지를 고를 수 있습니다. 수련장 공격 예고는 왼쪽 버튼 또는 T로 바꾸며, 정밀 회피 의뢰 중에는 자동으로 켜집니다. 수련장에서는 재화를 쓰지 않고 연습 중 체력이 1 아래로 내려가지 않습니다.

현재 대화는 본편 85장면·동료 30장면·기존 구조 보고 5장면·후일담 1장면·새 선택 의뢰 63장면으로 총 184장면입니다. 전체 메인·서브 퀘스트의 조건·대사·선택 결과는 `Docs/quest-script.txt`, 검토는 `Docs/quest-review.txt`, 검증 해시와 범위는 `QA/quest-verification.json`에 있습니다.

0.5.0에서는 대화를 출정 → 대치 → 정화 후 → 귀환 보고 순서로 새로 정리했습니다. 본편 75장면, 동료와의 선택 대화 30장면, 구조 보고 5장면, 후일담 1장면을 게임에서 읽을 수 있습니다. 공통 대사 324개와 선두별 응답 150개, 진행 상태별 NPC 응답 105개를 작성했습니다. 보고식 독백을 주고받는 대화로 바꾸고, 인물별 말투·호칭·망설임·반응을 구분했습니다. 텍스트 대화이며 음성 연기는 포함하지 않습니다.

뱌쿠야 → ‘조사 기록 확인’ → ‘대화록’에서 지난 장면을 액트와 사건 순서로 읽습니다. 당시 선두의 응답을 보존하며 읽기만으로 보상이나 진행이 변하지 않습니다. 이전 저장에 대화 이력이 없으면 진행한 장면을 현재 선두의 응답으로 복원하고 그 사실을 표시합니다. 아직 진행하지 않은 액트의 제목과 대사는 숨깁니다. 콘의 ‘동료와 이야기’는 해당 액트 의뢰를 받은 뒤 현재 선두와 동료 사이의 짧은 대화를 엽니다.

전체 대본과 여섯 인물의 말투 지침은 `Docs/character-dialogue-script.txt`, 장면·조건 목록은 `Docs/dialogue-index.json`, 작성 소스는 `Tools/prepare_dialogue.py`에 있습니다. 전체 대본에는 결말이 포함됩니다. `python Tools/prepare_dialogue.py`로 같은 게임 JSON과 대화록을 함께 내보냅니다. 기존 데이터 가져오기·캠페인 재생성도 이 대사 보강을 다시 적용합니다.

우라하라에게 액트 의뢰를 받고, 쿠카쿠의 균열 지도에서 출정하세요. 일반 병과 2~4기, 고정 네임드, 중간보스와 보스를 상대합니다. 방을 정화하면 오른쪽 출구까지 이동한 뒤 E 또는 ‘다음 방’을 눌러 진행합니다. 6개 던전을 마치고 우라하라에게 보고하면 다음 액트가 열립니다. 보고 보상은 한 번 지급합니다.

0.4.0에서는 30개 던전마다 출정 이유와 다음 단서를 연결하고, 보스 10명의 시작·종료 장면과 여섯 인물의 액트별 반응을 보강했습니다. 전투의 기억이 현실의 이름과 섞이는 ‘영해’와 여섯 동료의 선두·통신 역할을 첫 출정에서 설명합니다. 조사 기록은 5개 액트, 30개 구역을 따로 열람할 수 있습니다.

마을에는 우라하라·텟사이·콘·뱌쿠야·쿠카쿠가 실제 화면에 서 있으며 몸체 터치나 가까이서 E로 대화합니다. 액트 보고에 따라 귀환 등불 5개가 켜집니다. 각 던전 첫 방의 귀환 등불을 안내하면 체력 15%와 영압 15를 회복합니다. 액트마다 두 곳 이상 안내한 뒤 콘에게 구조 소식을 보고하면 골드 100·결정 2·회복 영자 1개를 한 번 받습니다. 영자가 가득 차면 대신 골드 40을 받습니다. 놓친 등불은 정화한 던전을 재현해 회수할 수 있습니다.

전투 배경은 강변·등대·지붕·가르간타 관문·백사막·실험실·운하·거울 회랑·그림자 통로·미래의 정원 등을 포함한 15종입니다. 6가지 배치와 10개 증원 방으로 진입 순서를 달리했습니다. 두 번째 일반 전투방에는 파도·낙하·돌풍·불안정 결계·그림자 환경 예고가 등장합니다. 범위를 피하거나 가까운 영압 장치를 E 또는 버튼으로 해제하면 해당 방의 환경 예고가 멈춥니다.

보스 10종, 고정 네임드 44종, 원작 진영을 바탕으로 한 일반 병과 16종을 구현했습니다. 근접·원거리·구역 공격·돌진·방어·비행 행동을 사용하며, 보스는 미끼·교차 사선·연격·환영·되돌림·미래 예고 등 서로 다른 패턴을 사용합니다. 공격 범위는 바닥에 표시하고, 회피 방법과 남은 시간은 중앙에서 안내합니다. 적 몸체를 터치하거나 왼쪽 ‘대상 변경’ 버튼을 눌러 표식·공격 대상을 바꿀 수 있습니다.

던전 최초 정화 보상은 경험치·골드·영자 결정·장비입니다. 파티 레벨과 장비는 여섯 인물이 공유합니다. 공격 영장은 피해를, 수호 영장은 최대 체력을 높이며, 텟사이의 장비 화면에서 비교·착용·즐겨찾기·강화를 사용할 수 있습니다. 강화는 비용을 표시하고 +5까지 확정 성공합니다. Act 3 보고 뒤 각성기 피해가 20% 증가합니다. 정화한 던전의 재현은 경험치·골드를 줄여 지급하며 최초 장비와 보고 보상은 반복하지 않습니다.

루키아는 냉기 제어, 오리히메는 회복·결계·반사, 요루이치는 돌진·다단 공격, 소이폰은 적별 표식과 마무리, 란기쿠는 재구름 설치·폭발, 우노하나는 회복·반격 태세를 사용합니다. 각 인물은 네 기술과 각성기를 가집니다. 마을 수련장에서는 자원과 조사 진행에 영향을 주지 않고 기술을 시험할 수 있습니다.

기본 공격이 맞은 직후 기술로 연결하면 회수 동작을 취소합니다. 강공격은 적을 밀고, 띄우기 뒤 공중 공격은 추가 피해를 줍니다. 보스는 강공격·반격·각성기로 자세 수치를 깎아 짧은 무방비 상태를 만들 수 있습니다. 타격 순간 정지, 경직, 피해 숫자, 적 소멸과 캐릭터별 효과음·궤적을 추가했습니다. 효과 줄이기는 화면 흔들림 등 표현만 줄이며 전투 규칙은 유지합니다.

터치 UI는 왼손 패드와 오른손 공격을 동시에 처리합니다. 패드를 위로 밀며 공격하면 띄우기, 점프 후 공격하면 공중 공격입니다. 메뉴에서 버튼 크기·선명도·효과음·대화 글자·효과 줄이기를 조절할 수 있습니다. 일시정지와 도움말은 이미 사용한 기술·다단 공격·재사용 시계를 보존합니다. 메뉴 뒤쪽 터치는 차단합니다.

정화한 방·던전·레벨·장비·재화는 자동 저장합니다. 귀환·패배·종료 후 마지막 정화 방 다음부터 재개하며, 미완료 방의 적 체력은 초기화됩니다. 저장 경로는 `Application.persistentDataPath/SpiritTide/profile-v1.json`입니다. 체크섬·복구본을 확인하고 손상 파일을 보존합니다. 0.1/0.2의 Act 1 보고 완료 저장은 골드·소모품을 유지해 Act 2 의뢰부터 이어집니다. 기존 진행 상태에 따라 이전 두 보스의 체크포인트를 새 캠페인의 대응 구역으로 옮깁니다.

`QA/verification.json`에 현재 빌드 GUID·실행 코드 해시·검사 결과를 묶습니다. 모델 검사는 여섯 캐릭터가 정상 체력과 실제 보상으로 전체 캠페인(180개 던전·684개 방)을 진행합니다. Windows 실행 검사는 1560×720와 2556×1179에서 실제 uGUI 렌더·포인터 이벤트·문자 높이·버튼 배치·지도·전리품·강화·보고·미래 사선 표시와 배경 15종, 보스 시작·종료 장면, 최대 글자 크기의 NPC 대화 600가지, 조사 기록 30페이지, 구조 보고와 장치 해제를 확인합니다. 회복 표시만 체력 80 조건으로 별도 검증합니다. 현재 검사 개수는 QA 보고서에 기록합니다.

대화 검증은 184장면을 여섯 선두로 해석한 1,104가지의 모든 페이지에 최대 글자 크기를 적용합니다. 실제 캠페인의 본편 85장면 기록, 동료 대화 30가지, 완료한 기본 장면 121개와 수행한 선택 의뢰 60장면의 대화록 이동, 당시 선두 보존, 저장 재시작, 이전 저장 복원, 미진행 장면·선택하지 않은 결말 잠금, 장면 중 귀환·건너뛰기를 확인합니다. 대본과 게임의 문장 일치는 `QA/dialogue-verification.json`의 해시와 검사 범위로 남깁니다.

의뢰 검증은 정상 체력으로 주요 조사 5개를 거치는 전체 캠페인, 선택 의뢰 18개 보고 결과의 실제 목표·중복 보상 방지·저장 복원, 두 화면 크기에서 선택 의뢰 15개의 실제 수락·탐색·장치·대화·수련·보고를 포함합니다. 엔딩 뒤 재현을 통한 선택 의뢰 완료가 메인 완료와 최초 정화 보상을 바꾸지 않는지, 진행 중인 Act 2의 같은 방에서 메인·서브 조사가 함께 남고 각각 완료되는지도 확인합니다.

`QA/experience-combat.mp4`는 정상 시작 체력으로 입력을 재생한 12초 영상입니다. 30Hz 고정 시뮬레이션 360장을 인코딩하고 같은 게임 효과음의 발생 시점을 합성했습니다. 성능 측정이나 시스템 오디오 녹음이 아닙니다. 재현·소스·해시는 `QA/experience-combat.json`에 있습니다. 인코딩 도구는 Python의 `imageio_ffmpeg` 패키지를 사용하며 게임 실행에는 필요하지 않습니다.

`Screen.safeArea`를 사용하며 2556×1179 가로 화면에는 예시 안전 영역으로 PC 검사를 수행합니다. 아이폰 OS·Metal·실제 멀티터치·발열·지속 프레임은 아직 검증하지 않았습니다. 목표는 60fps이며 측정된 아이폰 성능 수치가 아닙니다.

기존 성인 평행세계 비키니 v2 캐릭터 6장과 보스 10장은 원본 해시를 유지합니다. 0.3의 적 아틀라스 5장과 거점·액트 배경 6장에 더해, 0.4에서 전투 배경 10장·NPC 시트 1장·동작 시트 2장을 built-in image_gen으로 생성했습니다. 오리히메·우노하나는 선택한 키프레임을 사용하며 나머지 네 인물은 기존 그림과 코드 모션을 사용합니다. 일부 동작 생성과 우노하나 시트 정리 요청은 이미지 도구 안전 심사에서 거절되어 재시도나 다른 서비스로 우회하지 않았습니다. 원본 PNG 픽셀을 수정하지 않고 Unity의 크롭 메타데이터·피벗·선택 프레임으로 경계를 정리했습니다. 모든 인물과 적의 연속 애니메이션, 최종 외형 통일, 제작용 사운드·효과는 후속 작업입니다.
